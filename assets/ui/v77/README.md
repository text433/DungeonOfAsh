# UI v77

Original artwork generated with the built-in image generator, then cropped to individual transparent 48×48 PNGs with nearest-neighbor scaling. Source sheet is an original nine-cell atlas, not artwork extracted from another game.

Files: `joystick-base.png`, `joystick-knob.png`, `attack.png`, `ability.png`, `talent.png`, `pause.png`, `fullscreen.png`, `zoom.png`, `close.png`.

## Generation prompt

Use case: game production sprite atlas. Create ONE square transparent PNG UI texture atlas, exactly 3 columns x 3 rows, 9 equal cells, one isolated centered object in every cell, broad transparent gaps. No text, labels, numbers, scenery, mockup, grid lines, or shadows outside objects. Native look: crisp 48x48 pixel-art sprites enlarged nearest-neighbor. Dark fantasy mobile dungeon game consistent with chunky 0x72 DungeonTileset II world, but attractive tactile UI materials. Cohesive dark charcoal stone, worn muted bronze rim, subtle warm ivory edge highlights, restrained brown leather, turquoise only for magic. Use visibly stepped pixel silhouettes and clean large pixel clusters, not blurry shading, not vector flat icons, not ornate filigree. Shapes must be centered and perfectly front facing, same lighting upper-left, each fills about 72% of its cell. ROW 1: (1) circular joystick base, thin beveled bronze rim around dark stone circular recessed disk, small understated cardinal notches, empty center; (2) circular joystick thumb knob with raised reddish-brown leather face and bronze edge, same visual scale as other cells (software scales it down); (3) circular ATTACK button, stone and bronze ring, large two crossed ivory steel swords with dark brown handles, perfectly readable. ROW 2: (1) circular magic skill button, same ring, bold cyan protective shield with simple pale rune, restrained glow inside circle only; (2) small octagonal talent button, same material, large golden four-point star; (3) small octagonal pause button, same material, two bold ivory vertical bars. ROW 3: (1) small octagonal fullscreen button, same material, four ivory right-angle corner marks pointing outward; (2) small octagonal map zoom button, same material, one large ivory plus symbol; (3) small octagonal close button, same material, one large ivory X. A professionally consistent SHIPPABLE texture sheet, not concept art. Actual alpha transparency outside all nine elements. Strong silhouette, no extra gems, skulls, wings, or text.
